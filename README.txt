CIAO BELLA! — pizzeria / projekt do portfolio

Otwórz index.html w przeglądarce. Niczego nie trzeba instalować.
Na GitHub Pages prześlij całą zawartość tego folderu do głównego katalogu repozytorium: index.html, styles.css, script.js, favicon.svg i folder assets.

Funkcje: animowane wejście, ruchome detale i pasek tekstowy, menu z 3 kategoriami, szczegóły składników i alergenów, galeria zdjęć, demonstracyjny formularz stolika, menu mobilne i dolny pasek akcji na telefonie.
Formularz działa tylko lokalnie. Nie wysyła danych, nie sprawdza dostępności i nie potwierdza rezerwacji.

Marka, adres i szef kuchni są fikcyjne. Menu i ceny są przykładowe. Fotografie stockowe: Unsplash.
Fonty Barlow Condensed, DM Sans i Caveat pobierane są z Google Fonts. W razie braku internetu używane są fonty zastępcze.
